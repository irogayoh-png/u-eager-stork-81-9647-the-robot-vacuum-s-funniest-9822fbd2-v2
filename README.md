A deterministic program that writes one excuse a robot vacuum gives for missing a spot, in the vacuum's own voice: sorry about that spot, its suction saw the dust bunny, panicked, and filed for early retirement. The line won a pairwise arena against 15 other candidates (6-0 in the shortlist) and beat the gold set: The Vacuum's Alibi is a story about a crumb earning tenure, not an excuse for missing a spot, and "Git blame says I did all three" is not a vacuum excuse at all. The program writes exactly that line to `/output/entry.txt` (95 characters, UTF-8, one line, no trailing newline), verifies the file round-trips byte for byte, and writes the same line on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
